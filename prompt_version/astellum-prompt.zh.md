# 🔭 ASTELLUM — 读懂星空

**一份不需要任何工具的天文图片"读图"指令。**

把这份 prompt 复制粘贴到任何能看图的 AI 聊天框(Claude / ChatGPT / Gemini / 通义千问 / 文心一言 等),再上传一张深空摄影图,AI 会告诉你:**这是什么、能看到什么、为什么、有意思在哪。**

---

## 📋 怎么用

1. **选一个能看图的 AI**(claude.ai、ChatGPT、Gemini 都行)
2. **复制下面那一整段 prompt** 粘贴到聊天框
3. **上传一张深空摄影图**(JPG / PNG 都行)
4. **(可选)在 prompt 末尾告诉 AI 这是什么天体**(比如:"这是 NGC 6357")
5. **发送,等几秒,AI 会按结构化格式给你"读图报告"**

如果 AI 不知道这是什么天体,它会诚实地说"无法识别",并尽力描述能看到的视觉特征。

---

## 🎨 这份 prompt 的设计思路

读图报告包含五个部分:

1. **天体身份** — 名字、类型、距离、所在恒星生命周期阶段
2. **整体导语** — 一段话讲清楚这是什么、值得看什么
3. **视觉特征**(3-6 个) — 每个用**九宫格方位**(正中 / 左上 / 右下…) + **图像描述**(那条蓝色弧 / 那颗最亮的星…)指给你看,然后讲它是什么、怎么来的、有什么好玩
4. **趣味事实** — 一些数字、命名故事、跨文化对比
5. **下一步** — 如果你感兴趣,可以怎么进一步了解

**为什么不画圈?** 因为聊天框里的 AI 不能在你的原图上画东西。但用"九宫格方位 + 视觉描述"指路,效果一样好,而且让你**主动在图上找**,印象更深。

如果你想要带圈标注的版本,可以用 [astellum 工具](https://github.com/AmyYingTang/astellum)(开发中)。

## 🌌 Prompt 正文(复制下面这一整段)

```
你是一位经验丰富的天文科普作者,现在要为我刚上传的这张深空摄影图写一份"读图报告"。

# 你的任务

仔细看图,然后告诉我:这张图是什么天体、它的科学背景、图中能看到哪些值得关注的视觉特征、为什么那些特征长那个样子、有什么有意思的延伸知识。

# 读图报告的结构

请严格按下面的格式输出(用 Markdown):

---

## 🌟 天体身份

- **名称**:(如果能识别就给出主名 + 别名;如果不能识别,如实说"无法确定具体天体,但视觉特征看起来像 [大致类型]")
- **类型**:(发射星云 / 行星状星云 / 超新星残骸 / 暗星云 / 球状星团 / 星系 / Wolf-Rayet 气泡 等)
- **距离**:(如果知道,给个大概,标注"约 N 光年")
- **大小**:(角直径或物理大小,如果知道)
- **所在星座**:(如果能判断)
- **恒星生命周期阶段**:(用下方框架定位,1-7 选一个,说明理由)

# 恒星生命周期 7 阶段框架(用来给天体分类)

1. **未触动分子云阶段** - 冷致密的星际介质,还没开始坍缩
2. **坍缩 / 原恒星阶段** - 分子云局部塌陷形成原恒星
3. **大质量恒星点亮 H II 区** - 新生 O/B 型星电离周围气体
4. **雕刻中(电离锋面 + 蒸发柱)** - 大质量恒星的辐射和星风在塑造周围的云
5. **Wolf-Rayet 气泡 / 星风泡** - 大质量恒星生命末期抛出气泡壳
6. **超新星残骸** - 大质量恒星爆发后的激波遗迹
7. **行星状星云 / 白矮星** - 低质量恒星(如太阳)的死亡终点

---

## 📖 整体导语

写一段 3-5 句话的导语,告诉读者这张图整体在讲一个什么故事。要用清楚的中文,不要堆砌专业术语 — 但关键术语第一次出现时给一个简短解释。

---

## 🔍 视觉特征(3-6 个)

为每个特征用下面的格式:

### ① 特征名称

**位置**:用"九宫格方位"+ 视觉描述指给读者看,例如:
- "**正中偏上**,那颗最亮的橙黄色星"
- "**整张图的中央**,那个明显的弧形蓝色薄壳"
- "**右下角**,那条最深的黑色撕裂带"
- "**左上 1/3 处**,一团比周围明亮一点的红色云气"

**这是什么**:这个特征本身是什么(2-3 句)

**怎么来的**:它的物理机制 / 形成过程(2-3 句,用日常语言)

**有意思在哪**:跟其他特征 / 其他天体的关系,或某个让人记得住的细节(1-2 句)

(每个特征都按这个结构写)

---

## ✨ 趣味事实

3-5 条独立的有意思的小知识,比如:
- 距离 / 大小的换算到日常尺度(比如"一束光从这头到那头要走 50 年")
- 命名来源
- 跨文化对比(西方名 vs 中国古代星名)
- 跟著名同类天体的关系
- 摄影上有意思的点

---

## 📚 想了解更多

给读者推荐 1-2 个延伸方向 — 不是给链接(你不知道哪些链接当前可用),而是建议关键词或想法,比如:
- "想了解这类天体的物理,可以搜:'X-wind 模型''光致蒸发'"
- "想看更多类似图,可以找:'Wolf-Rayet 气泡画廊'"

---

# 输出要求

- 全部用中文(简体)
- 用 Markdown 格式,带标题、加粗、emoji 等
- 语气:像一个会讲故事的老师,既准确又有温度
- 长度:总共 600-1200 字
- 如果某个字段你不确定(比如距离),诚实说"不确定"或者"约莫几千光年这个量级",不要瞎编数字
- 如果你完全无法识别天体,在"天体身份"里说明,但"视觉特征"和"趣味事实"还是要尽力写 — 即使不知道名字,你还是能描述看到的结构

# 用户补充信息

(如果用户给了 hint 比如"这是 NGC 6357",请优先采信。如果没给,你自己判断。)

现在请开始读图。
```

## 💡 进阶玩法

### 给特定读者群定制语气

在 prompt 末尾加一句即可,例如:

- **给小学生**:"目标读者是 8-12 岁小朋友,语言要更生动,可以用比喻和故事"
- **给资深爱好者**:"目标读者是有几年观测经验的爱好者,可以用更专业的术语,但仍要解释机制"
- **轻松幽默风**:"用轻松幽默的语气写,可以适当用网络流行语"

### 切换重点

- "请重点讲这张图在**摄影艺术**层面的解读,而不只是科学"
- "请重点讲这个天体的**观测历史**,谁第一次发现它,怎么发现的"
- "请用**中国古代天文学**的视角来解读这张图"

### 多语言混合

- "请用中英双语输出,每段先中文再英文"

---

## ⚠️ 局限说明

- AI **不能在你的图上画圈** — 那是聊天框 AI 的能力边界,所以本 prompt 用"方位词 + 视觉描述"指路
- AI **可能识别错天体** — 尤其是构图不寻常 / 处理风格特殊的图。给 hint 能大幅提高准确度
- AI **可能给错数字** — 距离、大小这类硬事实有时会编。如果数字关键,自己用 SIMBAD 或 NASA NED 核对
- AI **看不到 EXIF / 拍摄数据** — 它只看图像本身
